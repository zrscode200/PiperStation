# Product

Piper Station is a central design and development workspace for one developer
working with Codex, Claude Code CLI or GitHub Copilot CLI across registered
projects. It connects exploration, deliberate planning, bounded implementation,
review and durable resumption. A hub may enable any combination of these CLIs.

Piper behavior has one source; runtime adapters connect it to native instruction,
skill, role and lifecycle facilities. Differences in native capabilities stay
explicit. Project source remains in project repositories and the hub owns its
project context and work records. Ordinary work stays lightweight.

The generated hub's detailed product contract lives in `core/shared/PRODUCT.md`.
